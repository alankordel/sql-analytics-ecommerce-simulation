# Business Cases

These analyses translate SQL concepts into business questions:

1. `01_sales_kpis.sql` — revenue, cost, profit, margin, average ticket and
   monthly growth.
2. `02_store_performance.sql` — store and regional productivity ranking.
3. `03_product_analysis.sql` — product/category revenue and profitability.
4. `04_customer_analysis.sql` — customer value and behavioral segmentation.

Run the scripts after `install.sql`.
